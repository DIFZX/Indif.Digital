# Client RSVP dashboard

Reading this as: an existing mobile dashboard for couples to review RSVP and send personal invitations. ENERGY 1 / RHYTHM 2 / MOTION 1.

Keep the existing InDif logo, system sans, white surfaces, slate text, and green sharing actions. Each menu has its own route and page content; the shared header and bottom navigation stay in place. The header's back link returns to the dashboard, while normal browser history follows visited pages.

The generator follows the task in order: guest name, personal link, editable message, preview, sharing. A plain textarea supports familiar editing on Android and iOS. Small text buttons insert automatic fields at the cursor, without adding an icon system. A green save button distinguishes storing the message for the couple from copying or opening WhatsApp. The message persists privately per invitation, while guest names remain temporary.

Keep new inputs at 16px to avoid iOS focus zoom, controls at least 44px high, visible keyboard focus, wrapping text, and enough bottom space above navigation. Use inline save, pending, unsaved, and failure states. No new illustration, decorative motion, or invented metrics.
